# Complementary fixed-panel comparison

Training-only greedy coverage at a two-test budget, compared with the saved
prevalence, host 4-mer and GenoPHI rankings. One ordered pair is fixed per
training split. Unknown source MLCs remain unknown.

See [results and reproduction](../../docs/complementary-panel-results.md),
[analysis protocol](protocol.json), and [implementation freeze](implementation.json).
The primary-panel gain does not extend to the B2 holdout; no stable general
benefit or low-prevalence rescue mechanism is established.
