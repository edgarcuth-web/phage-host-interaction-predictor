# Picard same-source extension

Audit all 225 source records outside the original 177, freeze admission by
source taxon/missingness and whole-component genomic overlap, then evaluate
the two already fixed panels without refitting or reselection.

[Results, all changed cases and reproduction](../../docs/picard-extension-results.md)
describe 138 admitted hosts in 114 new groups. The LF73_P1 pair rescues 11 and
newly misses three versus prevalence; the LF110_P2 pair loses nine net hits.
This is inspected same-study evidence, not independent validation.
